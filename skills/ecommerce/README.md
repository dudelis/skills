# Ecommerce Skills

Skills for ecommerce product research and content preparation workflows.

| Skill                                                     | Description                                                                                                                                                                                                                                                                                          |
| --------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [shopify-product-research](shopify-product-research/SKILL.md)             | Researches one skincare or dermocosmetics product, compiles a structured YuliSkin brief at `Products/[CompanyName]/[ProductName]/brief.txt`, and downloads 2 to 5 main product images into the same folder using sequential `[image-slug]-01` style names (lowercase ASCII handle slug).             |
| [shopify-product-create](shopify-product-create/SKILL.md) | Creates one new draft Shopify product from a shopify-product-research folder, using German default fields, best-effort English translations, existing metafields, handle generation, sequential product images, and duplicate-stop safety checks.                                                            |
| [shopify-product-update](shopify-product-update/SKILL.md) | Updates existing Shopify products from regenerated research files with dry-run diffing, guarded bilingual content updates, and append-only media handling.                                                                                 |
| [shopify-blog-write](shopify-blog-write/SKILL.md) | Prepares complete German/English YuliSkin articles locally from approved SEO briefs, then creates or updates Shopify drafts only after explicit confirmation, using supplied banners and existing associated collections. |
| [shopify-email-write](shopify-email-write/SKILL.md) | Plans German (optionally English) YuliSkin marketing emails with layout variants, subject lines, preview texts, and banner prompts, then writes paste-ready HTML/Liquid blocks for the Shopify Email Custom Liquid section with a local preview and validation. |
| [shopify-slideshow-create](shopify-slideshow-create/SKILL.md) | Creates one new German/English YuliSkin homepage slide: intake, copy, image prompt, 1536×1024 image prep, alt text, and a new Shopify `slideshow` metaobject with English translations, plus a checklist for wiring it into the slideshow. |
| [shopify-company-research](shopify-company-research/SKILL.md)             | Researches one skincare or dermocosmetics brand, produces a Shopify-ready collection-page brief in German and English at `Collections/[CompanyName]/brief.txt`, downloads the brand logo, and discovers products from the brand site into `products.csv` for parallel fan-out to `shopify-product-research`. |
| [shopify-prices-compare](shopify-prices-compare/SKILL.md) | Monitors one brand across competitor websites, capturing historical prices and promotions into one cumulative CSV file per competitor, compared against distributor recommended prices or YuliSkin.de prices. |
