# Email Write Shopify

Produce one Shopify Email body as a Custom Liquid block (banner + content) that
sits between the native header and the native footer (address, unsubscribe).
Shopify has no API for Shopify Email, so the result is local files the user
pastes. Address German readers as "du".

## Quick start

> Create a campaign email for 15 % off pHformula until 30.11. Code PH-15,
> min. 60 €. Show 4 products and a countdown. Suggest variants first.

## Required boundaries

- Read-only in Shopify (products, collections, articles, discounts), except the
  banner upload to Shopify Files, which needs explicit confirmation each time.
- Never create or change discounts. The user creates them and supplies the code;
  verify it and stop on any mismatch with the email text.
- The user picks a layout variant and approves the key copy points before the
  final HTML is written. Variants and subject lines are suggestions until chosen.
- Product, ingredient, and efficacy claims come only from verified sources:
  the live product page, the brand site, or `Products/<Company>/<Product>/brief.txt`.
  Ask when a claim cannot be verified; never invent one.
- Every image has alt text; never use SVG or WebP images.

## Workflow

1. **Intake.** Read [email-types.md](references/email-types.md). Ask the main
   type and add-on modules, then the fixed questions (occasion, send date,
   theme, language, banner source, greeting) and the type's questions. Skip
   what the user already supplied.
2. **Resolve data.** Read [shopify-email-contract.md](references/shopify-email-contract.md).
   Verify the store is YuliSkin, then resolve products, collections, logos,
   articles, and the discount. Report mismatches, unpublished articles, and
   SVG/WebP images now.
3. **Propose.** Present 2–3 layout variants (ordered block list + one-line pitch),
   3 subject lines, and 3 preview texts per [copy-rules.md](references/copy-rules.md).
   Wait for the user's choice and approval of the key copy points.
4. **Banner.** If no banner is supplied, ask what it should show, then write a
   ChatGPT/Gemini prompt per copy-rules. Write alt text. Upload to Shopify Files
   only after explicit confirmation and record the CDN URL.
5. **Write.** Assemble the block from [blocks.md](references/blocks.md) and fill
   the theme tokens from [brand-themes.md](references/brand-themes.md). With a
   countdown in the middle, split into `email-part-1.liquid` and
   `email-part-2.liquid`. Save the brief and files (see Outputs).
6. **Check.** From this skill folder run:

   ```bash
   python scripts/build_preview.py <email-folder>
   python scripts/validate_email.py <email-folder> --check-urls
   ```

   Also compare the discount's live value, minimum order, and end date with
   the email text and fine print. Fix every failure; never skip one silently.
7. **Hand over.** Give the folder path, the chosen subject and preview text,
   and paste instructions from the contract (section order, countdown
   settings, email background colour, send a test). Ask whether English is wanted.
8. **English (optional).** After the German version is approved, write
   `email-en.liquid` (or `email-en-part-*.liquid`), English subject and preview
   text, and rerun step 6 with `--lang en`.

## Outputs

Save everything in `Emails/<YYYY-MM-DD>-<slug>/` (send date if known, else today;
lowercase ASCII slug):

| File | Content |
| --- | --- |
| `brief.md` | Front matter (subject, preheader, discount, countdown, theme) + intake answers, chosen variant, sources |
| `email.liquid` or `email-part-1/2.liquid` | The paste-ready block(s) |
| `email-en*.liquid` | Optional English block(s) |
| `preview.html` / `preview-en.html` | Generated by `build_preview.py`; do not hand-edit |
| `banner-prompt.md` | Banner prompt and alt text, when a prompt was written |

The `brief.md` front matter format is defined in [copy-rules.md](references/copy-rules.md#brief-front-matter).
