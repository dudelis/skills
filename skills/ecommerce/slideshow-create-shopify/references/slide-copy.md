# Slide copy: heading, description, button, English

The three texts map to `slideshow` metaobject fields: `heading` (the slide
title), `subheading` (shown as the slide description), and `button_label`.

## Limits

Count every final string in code, in both languages:

| Field | Limit |
| --- | --- |
| `heading` | ≤ 45 characters, punchy (e.g. "Neu im Shop: pHformula", "Liften. Definieren. Strahlen.") |
| `subheading` | one sentence, ≤ 110 characters |
| `button_label` | one pair from the button set below |

## Voice

- Neutral and expert: name the product and its benefit instead of addressing
  the reader, so the copy works without du/Sie.
- Keep real ä/ö/ü/ß. Only the handle and filenames are ASCII.
- Use "–" (en dash) between a name and its benefit, as the live slides do.
- At most one exclamation mark per slide; no emojis.
- A promotion slide names its end date when the user gave one ("bis 30.11.").

## Drafting

- **Exact wording supplied:** keep it. Report any limit overrun or unverified
  claim and propose the smallest fix.
- **Key message supplied:** propose 2–3 German heading + description pairs,
  each with a different angle (news, benefit, ingredient/technology).
- Every claim traces to a source recorded in the brief's `## Sources`.

## Button set

| Use | DE | EN |
| --- | --- | --- |
| Product or brand news | Jetzt entdecken | Discover now |
| Direct purchase | Jetzt kaufen | Shop now |
| Promotion | Jetzt sparen | Save now |
| Blog article | Zum Artikel | Read article |
| Background / how-to | Mehr erfahren | Learn more |
| Whole shop | Online Shop | Online Shop |

A label outside the set is allowed only when the user asks for it; it stays
≤ 20 characters in both languages.

## English

- Write English after the German draft, then present both for one approval.
- Adapt naturally rather than word for word, within the same limits. Keep
  product names, numbers, and dates identical; write dates as "30 November".
- The link is not translated: one absolute `https://yuliskin.de/...` URL with
  no `/en` prefix serves both languages.
